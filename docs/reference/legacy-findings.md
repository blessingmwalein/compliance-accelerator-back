**A.2 Scoring (and conflicts to design out).**
- Area exposure = sensitivity × severity × likelihood (1–125); Low ≤25, Medium ≤60, High ≤90, Critical ≥91. Labels — sensitivity: Public, Internal, Confidential, Restricted, Critical; severity: Minimal, Minor, Moderate, Major, Catastrophic; likelihood: Rare, Unlikely, Possible, Likely, Almost Certain. Gap = target − current (0–4 levels). Maturity: 1 Initial, 2 Managed, 3 Defined, 4 Quantitatively Managed, 5 Optimizing (other files say "Quantitative", "Qualitatively Managed", "Ad-hoc/Developing…").
- Risk register is a separate 1–25 model: likelihood × impact; Critical ≥20, High ≥12, Medium ≥6, else Low; residual = residual L × residual I (only the score was persisted).
- Conflicts: dashboard heatmap uses likelihood × severity with ≤6 / ≤12 / ≤20 cut-offs (one band lower than the register at 6, 12, 20) and ignores sensitivity; the gauge maps `score/125` to <24 % / <48 % / <80 % (= <30 / <60 / <100, contradicting the area bands); "compliance %" is really a maturity index (level 1 = 20 %) with three threshold sets (≥80/60, ≥75/50, ≥80/60/40); framework comparison used substring matching on 8 keywords ("Security Measures" never matched template "Security Safeguards"); target maturity was hard-coded to 5; templates defaulted `current_maturity` to 2 and carried no `framework`.
- Remediation task: priority = risk level; due +14/30/60/90 days (Critical/High/Medium/Low); auto-created per area with gap > 0 and no open task. RoPA review: due-soon ≥150 days, overdue ≥180 days or status "Needs Update"; missing date counted as overdue (bug).

**A.3 Eisenhower.** 5 urgency questions (`manual_handling`, `no_controls`, `regulator_deadline` (90 days), `active_breach`, `third_party_access`) + 5 importance questions (`sensitive_data`, `high_volume` (>500 subjects), `cross_border`, `core_business`, `regulatory_obligation`). Urgent = ANY urgency ticked; important = ANY importance ticked. Do Now (U∧I), Delegate (U∧¬I), Plan (¬U∧I, 30–90 days), Eliminate (neither). Persisted: `urgent`, `important`, `priority_quadrant` — answers were **not** persisted; zero answers became "Eliminate". Owner suggestions: Senior Compliance Officer/DPO; IT Support/Operations Lead; Compliance Officer/BU Head; (Eliminate: "Intern/Junior Analyst" — inappropriate for compliance obligations).

**A.5 AI features.** Per-area advisor (inputs: name, framework, description, current maturity; output: ratings with justifications, target maturity, gap analysis, urgent/important) and tenant-wide assessment (four unfiltered list calls aggregated in the browser; output: overall level, score, summary, high-risk areas, gaps, mitigations, priority actions {action, priority, deadline, responsible_role}, risk trends). Neither persisted results, provenance or consent; output numbers unvalidated; errors via `alert()`/generic toast.

**A.7 Workflows described in the legacy manual (treat as unverified).** Governance → remediation (score → exposure + quadrant → treatment → task with due date → resolve → evidence → next review); Breach (log → risk assessment → regulator-deadline check → notify regulator → reference number → notify subjects if high risk → close with lessons learned; legacy code only had Open/Closed); DSAR (received with unique id → identity verification → assigned → SLA countdown → Received → In Progress → Completed → evidence → reminder; generic "30-day" deadline, no per-framework table); Training (publish/assign → progress → quiz with minimum score → certificate → Completed).

**A.8 Reports.** Compliance Status (portrait: executive summary, key metrics, framework current/target/gap, optional AI page), RoPA (landscape: totals, table, 12-field detail), Governance Assessment (summary, table, High/Critical detail), Maturity & Gap (score bar, per-framework, top-15 gaps, recommendations, DSAR/breach counts), Consolidated DPO (landscape: cover, contents, up to 7 optional sections — governance, RoPA, risks, lawful basis, DSARs, breaches, retention; date range with presets; "CONFIDENTIAL — DPO Report" footer). Legacy faults: contents overflow at ≥5 sections, date window hid stale-but-open records, retention ignored the window, "open risks" excluded In Treatment, no continuation headers, silent truncation, glyphs outside the font range.

**A.9 Training.** Score = round(correct/total × 100); pass ≥ `passing_score` (default 70); unlimited retries; correct answers shipped to the client (design out); certificate = landscape PDF (name, course, framework, date, signature line, certificate id — id generation absent); auto-assign = published + mandatory courses by role→framework map ∪ company frameworks, due +30 days, no learner notification.

**A.10 Notifications.** Task reminders: manual "send" button, 7-day window, only to assignees whose value contains "@", `reminder_sent` set but never read (re-sent on each click), gated to Starter/Growth plans. Auto-alerts: DPO emailed on new breach and on overdue DSAR; skipped silently without `dpo_email`; legacy `SendEmail` only reached registered users.

**A.11 Plans.** Starter (core modules, ≤5 users), Growth (≤15, basic reporting), Professional (≤25, advanced reporting), Enterprise (unlimited, API access, dedicated support). Visibility toggle existed in company settings; hiding all plans reverted to "all visible".

**A.12 Anti-patterns to design out.** New areas defaulted to maturity 2; missing data treated as zero/worst case; target fixed at 5; derived values (exposure, level, gap) persisted and stale; client-only validation and permission checks; two `useAuth` hooks; role sets that disagree; hard-coded plan/framework lists (BDPA/NIST omitted); onboarding progress in `localStorage`; unscoped `list()` calls and `Company.list()[0]`; sequential non-atomic bulk creates; swallowed audit errors with client-side timestamps; per-card unbounded fetches aggregated in the browser; free-text owners and business units; magic values ("company-wide", "Unassigned"); UI state (`_nameSelection`) in persisted data; quiz answers client-side; certificate HTML interpolating unescaped names; `alert()` errors; dynamic Tailwind class names.
